# Playwright Login Automation

Automated login tests using Playwright + TypeScript.

## What this project tests
- The Internet Herokuapp - Login
    - Valid login succeeds
    - Login fails with wrong password
    - Login fails with wrong username
    - Login fails with empty fields
- The happy-playpen.lovable.app - Login 
    - Valid login succeeds
    - Login fails with wrong password
    - Login fails with wrong username
    - Login fails with empty fields

## How to run
```bash
npm install
npx playwright test
